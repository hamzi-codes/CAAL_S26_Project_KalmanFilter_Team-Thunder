# CAAL_S26_Project_KalmanFilter_Team-Thunder
A Computer Architecture and Assembly Language project on 3D motion estimation using Linear and Extended Kalman Filters.

This project focuses on estimating 3D motion using a constant jerk model and Kalman filtering techniques. The aim is to model, derive, and later implement Linear and Extended Kalman Filters for state estimation under uncertainty.
